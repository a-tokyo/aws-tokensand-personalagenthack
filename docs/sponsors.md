# Sponsor tools in Marco: one line each

Use these lines on the slides and in the submission. Status: **live** = it runs in the demo. **wip** = we are wiring it now.

| Sponsor | One-liner | Status |
|---|---|---|
| **Cognee** | Marco's long-term memory: every past trip, hotel and habit, recalled with its source. | live |
| **Senso** | The company travel policy as a context layer: every choice is checked against policy, with a citation. | live |
| **SingleStore** | The audit trail: one row per decision, with its source, model and cost. | live |
| **Statsig** | A safety switch: the `auto_submit` gate stays off, so a human approves every purchase. Every step is an event. | live |
| **Amplitude** | Agent analytics: each step of each trip is a tracked event, so we see where the agent spends time and money. | live |
| **Persona** | Planned: verify that the human who clicks "approve" is really Tokyo. | next |
| **Firedrill** | Simulates a plan change and a "skip approval" attack to test Marco before real bookings. Scores 99.3 and 98.8. | live |
| **Superlinked SIE** | Superlinked SIE: reranks Marco's memory recall, so the right habit comes first. | live |
| **Guild** | Planned: host Marco as a managed agent. | next |

## The pitch in one line

Marco does the travel admin that Perk and Navan still leave to people. It remembers your habits, checks the policy, finds the best value, books and reschedules, and keeps one human click for accountability. Every step is on an audit trail.
