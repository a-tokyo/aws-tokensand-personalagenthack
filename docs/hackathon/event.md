## Challenge

Build a shopping agent with an audit trail. The agent uses reliable context to decide, takes a meaningful action, and shows the information and steps behind what it did. Mid-event the organisers said it does not need to be strictly shopping.

## Submit

- A GitHub repo that reviewers can open.
- A short demo video with a shareable link.
- What we built and the tools we used.
- Team names and contact emails.
- Optional: a working website and a screenshot.
